# Supplementary material

[TIM_supplementary_material.txt](TIM_supplementary_material.txt) is UTF-8 text and contains Parts A–E. A locator for all deferred material appears at the beginning. Part E reports trial-level checks, calibration scores and ranks, protocol history and primary DOI verification.
